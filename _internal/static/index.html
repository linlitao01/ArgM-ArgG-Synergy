Data Input (M1 Data Management)

Two data levels are supported: the index level (province, year, mech, green; dcoord optional — when present the paper-convention coordination degree is used directly, otherwise it is computed automatically) and the indicator level (province, year, indicator columns; full pipeline: standardization → entropy weights → indices → coupling coordination → forecasting). The province column accepts Chinese names (Shanghai/Jiangsu…), and Excel workbooks with one sheet per year (sheet names 2022…) are stacked automatically.

Indicator System (M2–M3)

The 30 paper indicators are preset (15 mechanization + 15 greening). After uploading indicator-level data you can adjust each indicator's direction below, then compute the entropy weights. Weights are normalized within each subsystem (paper convention).

Composite Indices and Coupling Coordination (M4)

Indicator level: U = Σ w·x′ (entropy aggregation), paper-convention index = U − 0.01 (constant-safeguard shift). Index level: mech/green are used directly. Coupling coordination: C = 2√(U₁U₂)/(U₁+U₂), T = αU₁+βU₂, D = √(CT).

Forecasting and Reliability (M5 · Algorithm 1)

Core: GM(1,1) (paper conventions, with posterior-error-ratio C / small-error-probability P grading, 1000-resample residual bootstrap 90% intervals, and ARIMA(1,1,0)/Holt cross-model checks). Nonlinear enhancements: Verhulst grey model (dx/dt+ax=bx²), NARX-BP neural network (sliding-window recursive forecasting), and quadratic polynomial trend, compared series by series with direction-disagreement flags.

Early-Warning Dashboard (M6)

Warning rules (the two paper §2.5 examples)
1. "greening decline with a reliable grade" — a province's greening index declines toward 2030 under a reliable forecast (Grade I/II) → "greening setback" risk;
2. "mechanization rising while greening stagnant" — mechanization reliably rises while greening stays basically flat (2030 change < 0.02) → "structural imbalance" risk (fast mechanization, slow greening).
Additionally: Grade III/IV unreliable flags and cross-model direction-divergence flags. Above, the per-province coordination degree D trend chart (observed + forecast extension); below, the risk matrix = province × variable.
